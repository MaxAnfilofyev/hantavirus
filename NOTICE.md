This repository does not redistribute AlphaFold Server raw outputs.

Excluded materials include downloaded AlphaFold Server ZIPs, model `.cif` files,
full prediction JSON files, PAE arrays, contact-probability arrays, pLDDT tables
derived from raw outputs, and screenshots of predicted structures.

Some qualitative structural comments in the reports were informed by local
AlphaFold Server predictions. AlphaFold Server outputs and derivatives are
subject to the AlphaFold Server Output Terms of Use:

https://alphafoldserver.com/output-terms

These notes are for non-commercial, theoretical research discussion only. They
are not intended for clinical, diagnostic, therapeutic, docking, screening,
machine-learning-training, or public-health decision-making use.
